A one-line robot pickup line for The Robot Pickup Line Championship on make.fun. The joke grows out of how machines start a conversation: the robot opens with its usual formal handshake, the negotiation fails, and instead of pretending it knows what it is doing, it admits the failure honestly and turns it into a compliment — the person in front of it simply falls outside anything its protocol was built to handle. The charm comes from that open admission of its own limits, and the punchline lands at the very end, where the robot stays in its own machine vocabulary and asks, in protocol terms, to keep talking.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (UTF-8, a single line, no trailing newline).
